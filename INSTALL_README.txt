THE LEAGUE LEDGER - INSTALLATION

1. Keep your existing JSON backup safe.
2. Open the new Fantasy_Recap_Builder.html and import your JSON backup from Backup.
3. To install as an Android home-screen app, upload ALL files in this ZIP together to a static HTTPS host (such as GitHub Pages).
4. Visit the hosted Fantasy_Recap_Builder.html URL in Chrome, then menu > Add to Home screen > Install.
5. Import your backup again inside the installed app; browser file storage and installed-app storage may differ.
6. Export JSON backups regularly. Do not upload your backup JSON to the public hosting folder.

The local HTML file also works offline when opened from Files, but proper PWA installation needs HTTPS hosting.
ESPN API fetching may be blocked by CORS; manual ESPN JSON import remains supported.
